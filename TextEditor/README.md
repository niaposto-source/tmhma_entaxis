# Επεξεργαστής Κειμένου (Android)

Απλός επεξεργαστής απλού κειμένου για Android, γραμμένος σε Kotlin (AppCompat + Material 3).
Δεν χρειάζεται καμία άδεια: τα αρχεία ανοίγουν και αποθηκεύονται μέσω του επιλογέα αρχείων του συστήματος.

## Λειτουργίες

- Νέο / Άνοιγμα / Αποθήκευση / Αποθήκευση ως (UTF-8)
- Αναίρεση και επανάληψη (με συγχώνευση διαδοχικών πληκτρολογήσεων)
- Εύρεση και αντικατάσταση (μία ή όλες, με ή χωρίς διάκριση πεζών/κεφαλαίων)
- Μετάβαση σε γραμμή
- Γραμμή κατάστασης: γραμμή/στήλη, λέξεις, χαρακτήρες
- Αναδίπλωση γραμμών, γραμματοσειρά σταθερού πλάτους, μέγεθος γραμμάτων, σκούρο θέμα (οι ρυθμίσεις αποθηκεύονται)
- Ερώτηση για μη αποθηκευμένες αλλαγές πριν από νέο/άνοιγμα/έξοδο
- Ανοίγει αρχεία κειμένου από άλλες εφαρμογές και δέχεται «Κοινοποίηση» κειμένου
- Συντομεύσεις με πληκτρολόγιο υλικού: Ctrl+S, O, N, Z, Y, F, G
- Ελληνικά (προεπιλογή) και αγγλικά

Όριο μεγέθους αρχείου: 5 MB. Αρχεία που μοιάζουν δυαδικά απορρίπτονται.

## Build

Απαιτείται JDK 17+ και Android SDK (platform 34).

```bash
cd TextEditor
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Εναλλακτικά, άνοιγμα του φακέλου `TextEditor` στο Android Studio.
Το workflow `.github/workflows/android-build.yml` χτίζει το debug APK σε κάθε push και το ανεβάζει ως artifact.

Το `applicationId` είναι `com.example.texteditor` — αλλάξτε το στο `app/build.gradle.kts` πριν από δημοσίευση.
